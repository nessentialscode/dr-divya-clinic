# Premium Dental Clinic — Phase 1

## Goal

Build the complete single-page dental clinic experience at `/`, matching the supplied references rather than using a generic healthcare template.

## Structure

- Compact over-image navigation with a real mobile menu.
- Cinematic image-led hero with split sans/italic headline, appointment CTA, clinical note, and floating trust score.
- Spacious philosophy statement framed by two cropped lifestyle portraits.
- Two-column values section: four compact cards beside an editorial statement.
- Four specialist cards in one desktop row and a touch-scroll rail on mobile.
- Three testimonials with one photographic feature card and two pale editorial cards.
- Pale care-plan section with a layered floating pricing card.
- Unified dark newsletter and multi-column footer.

## Visual System

- Warm ivory canvas, near-black ink, pale lime accent, muted gray, and restrained white.
- Modern sans-serif for interface/body copy with an elegant italic serif for selected phrases.
- Tight, Swiss-inspired alignment; generous whitespace; compact rounded corners; minimal shadows.
- Purpose-made dental/lifestyle imagery matching the crop, warmth, and photographic scale of the references.
- Restrained motion only: button lift, card elevation, image scale, and accessible menu transitions.

## Technical Details

- Modular React components with specialist, value, testimonial, and plan data separated from markup.
- Semantic sections, keyboard-visible focus states, labels, alt text, and reduced-motion support.
- Tailwind v4 semantic tokens in the global stylesheet; no new runtime dependencies.
- Unique home-page title, description, Open Graph metadata, and Twitter card metadata.
- Validate desktop and mobile layouts in the running preview, then provide a finished desktop screenshot.
