# Premium Smile Studio

You are a senior product designer and frontend engineer specializing in premium healthcare websites.

I want you to build the first structural/UI version of a premium modern dental clinic website based on the attached visual reference images.

IMPORTANT:
The supplied images are the visual source of truth.

Do NOT simply create a generic dental website.

Reconstruct the visual language, composition, spacing, hierarchy, proportions, typography relationships, card styles, image treatment, colors, and overall editorial feel shown in the references.

The website should feel like a premium modern dental brand — sophisticated, minimal, editorial, trustworthy, warm, and contemporary.

==================================================
PRIMARY OBJECTIVE
==================================================

Build the complete frontend structure of the website.

This is Phase 1.

Prioritize:

1. Visual structure
2. Component architecture
3. Responsive layout foundation
4. Typography hierarchy
5. Spacing system
6. Image placement
7. Buttons
8. Cards

10. Basic interactions

==================================================
DESIGN DIRECTION
==================================================

The visual direction is:

Premium dental healthcare

- editorial design
- modern Swiss-inspired layout
- soft clinical aesthetic
- sophisticated typography
- subtle organic shapes
- large photography
- restrained animation
- generous whitespace.

The design should NOT look like:

- a generic dental template
- a typical medical SaaS dashboard
- a cheap clinic website

The experience should feel closer to a premium lifestyle/wellness brand while still communicating medical professionalism.

==================================================
RESPONSIVE DESIGN
==================================================

The website MUST be fully responsive.

Desktop:

- large editorial compositions
- generous whitespace
- horizontal doctor cards
- large hero photography
- two-column layouts where appropriate

Tablet:

- intelligently collapse multi-column layouts
- preserve hierarchy
- reduce spacing progressively

Mobile:

- single-column layout where appropriate
- horizontal scrolling for specialist cards if visually appropriate
- properly sized typography
- touch-friendly buttons
- readable body text
- no horizontal overflow
- navigation becomes hamburger
- images retain their intended visual impact

Do NOT simply scale the desktop layout down.

Design mobile intentionally.
